# 🎬 AFilm Bot

**An AI-powered Telegram bot for personalized movie and TV series recommendations.**

AFilm Bot is an intelligent recommendation bot built with Python that helps users discover movies and TV series based on their preferences, interests, and viewing history.

The project combines AI Agents, Large Language Models (LLMs), Semantic Search, and Collaborative Filtering to deliver personalized recommendations through a conversational Telegram interface.

## 🎯 Project Goal

The main goal of AFilm Bot is to go beyond traditional recommendation systems by providing an interactive and personalized experience.

Instead of simply matching keywords or displaying popular titles, the bot can understand natural-language requests, interact with its internal tools, analyze user preferences, and generate recommendations tailored to each user's interests.

## ✨ Key Features

- **AI-Powered Conversations:** Interact with users through natural language and understand their movie-related requests.
- **Personalized Recommendations:** Generate recommendations based on user preferences, feedback, and viewing history.
- **Hybrid Recommendation System:** Combine Semantic Search, Collaborative Filtering, and Business Rules to improve recommendation relevance.
- **Intelligent Tool Calling:** Use specialized tools to access information, retrieve data, and perform recommendation-related operations.
- **User Preference Management:** Take users' likes, dislikes, and watched movies into account.
- **Conversation Management:** Maintain conversation history and manage contextual information across interactions.
- **Movie and TV Series Information:** Retrieve relevant information about movies and series through dedicated tools.
- **Self-Description Capabilities:** Include specialized tools that allow the agent to identify and explain its own capabilities and provide information about its developer.

## 🧠 Development Approach

AFilm Bot was independently designed and developed, with its architecture, recommendation pipeline, database interactions, and AI agent integration implemented as part of the project.

The project focuses on combining established machine learning and AI technologies into a complete, functional software application rather than building an isolated model or a simple chatbot.

No AI coding agents were used to generate or implement the project's code. The architecture, core logic, algorithms, and system integration were developed independently.
